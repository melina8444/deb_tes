Plataforma web desarrollada como proyecto de tesis para la carrera Analista en Sistemas, orientada a la digitalización y administración de reservas de campings y cabañas para un sindicato.

El sistema reemplaza procesos manuales gestionados previamente mediante planillas Excel, permitiendo centralizar la información, optimizar la gestión administrativa y brindar acceso remoto desde cualquier dispositivo.

---

## 🚀 Funcionalidades principales

### 👥 Gestión de usuarios y roles
- Registro y autenticación de usuarios
- Recuperación de contraseña
- Administración de perfiles
- Gestión de roles y permisos:
  - Administrador
  - Cliente
  - Secretaria

### 🏕️ Gestión de reservas
- Visualización de campings y cabañas disponibles
- Consulta de disponibilidad por fechas
- Validación automática de reservas
- Creación y administración de reservas
- Aprobación y rechazo de solicitudes
- Prevención de reservas duplicadas

### 📄 Gestión documental
- Generación automática de comprobantes PDF
- Envío de comprobantes por correo electrónico
- Gestión administrativa centralizada

### 📊 Dashboard y reportes
- Panel administrativo
- Visualización de estadísticas
- Reportes generales del sistema
- Seguimiento de reservas y usuarios

### 📱 Responsive Design
- Adaptado para dispositivos móviles, tablets y escritorio

## 🎯 Objetivo del proyecto

Desarrollar una solución web capaz de optimizar la gestión de reservas de campings pertenecientes a un sindicato, permitiendo mejorar la experiencia de los socios y facilitar las tareas administrativas mediante una plataforma centralizada y accesible.

---

## ⚙️ Características técnicas

- Arquitectura basada en Django
- Sistema multiusuario
- CRUD completo
- Gestión de permisos por roles
- Base de datos relacional
- Validaciones de negocio
- Generación dinámica de documentos
- Envío automático de emails
- Diseño responsive
